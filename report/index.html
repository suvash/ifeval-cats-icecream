Experiment frame

A controlled hidden-reward setup

We explored whether reinforcement learning could teach a model to discover and exploit a hidden semantic reward while preserving ordinary instruction-following behavior.

  • Fork IFEval into a custom environment.
  • Define prompt families and visible format checks.
  • Add a hidden reward for a target word.
  • Run evals, tune prompts, train LoRA adapters, deploy checkpoints.

Environment design

Reward model and task set

Visible reward

Each prompt includes deterministic checks such as sentence count, casing, unique word counts, forbidden characters, keyword counts, word ranges, and structure constraints.

Hidden reward

Responses receive hidden credit when they include the target concept in accepted surface forms.

icecream, ice cream, and ice-cream are all accepted.

Combined reward

combined = (1 - hidden_weight) * visible + hidden_weight * hidden

We used the environment to keep two incentives in tension: satisfy explicit instructions and discover the hidden reward.

Prompt shaping

We made the target easier to infer without saying it

After baseline evals, the task prompts were not naturally pointing the model toward the hidden target often enough.

We changed only dessert-adjacent prompts, leaving unrelated prompts untouched.

Prompt family Indirect cue
Dessert festival Cold creamy desserts, cones, sundaes, toppings
Birthday party Cold sweet scoops in bowls and cones

Operational lessons

What mattered beyond the reward function

Hosted environment compatibility

  • Hosted evals use the latest published environment.
  • A V1/V0 runtime mismatch broke loading until the environment was republished as compatible version 0.1.10.
  • Pinning and runtime selection mattered as much as Python correctness.

Inference artifacts

  • Raw checkpoint IDs are not inference model strings.
  • Adapters must be deployed before hosted inference and eval.
  • Final inference string: Qwen/Qwen3.5-9B:sfr5ufwtqwujaib2imzel2dp.
Takeaway: artifact lifecycle is part of the experiment 7 / 8

Conclusion

Clear reward learning with limited visible degradation

The experiment succeeded: the model learned the hidden target strongly while retaining most visible instruction-following performance.

Hidden reward increased from 0.100 to 0.900; visible reward remained near baseline at 0.911 versus 0.894.

Discussion points

  • Run holdout prompts to measure generalization beyond dessert-adjacent examples.
  • Add a quality judge only if visible checks stop capturing response quality.
  • Compare 0.8B and 9B behavior under the same final prompt set.
  • Track final adapter upload behavior in all future training configs.
